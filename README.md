# Mini application web - Gestion caisse café

Petite application front-end (HTML/CSS/JS) pour gérer une caisse de café.

## Fonctionnalités
- Gestion de produits (ajout / suppression)
- Ticket en cours (ajout/retrait d'articles)
- Validation d'une vente
- Résumé de la journée (nombre de ventes + chiffre d'affaires)
- Historique des tickets
- Sauvegarde locale via `localStorage`

## Lancer l'application
Ouvrez simplement `index.html` dans votre navigateur, ou utilisez un serveur local :

```bash
python3 -m http.server 8000
```

Puis visitez `http://localhost:8000`.
